# Reports

This directory contains summary and audit reports.

## Structure

```
reports/
  audit/           - External audit reports
  testing/         - Test summary reports
  performance/     - Performance test reports
  security/        - Security audit reports
  acceptance/      - Acceptance reports
```

## Report Types

- **Audit Reports** — External audit findings and recommendations
- **Test Reports** — Summary of test execution and results
- **Performance Reports** — Benchmark results and analysis
- **Security Reports** — Security assessment findings
- **Acceptance Reports** — Stage acceptance documentation

## Report Format

Reports follow the template in `stages/templates/report-template.md`.

## Referencing Evidence

Reports should reference evidence files:

```markdown
See: `evidence/stage-NN/validation.txt`
```
