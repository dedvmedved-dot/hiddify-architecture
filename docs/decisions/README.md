# Architecture Decision Records

This directory contains Architecture Decision Records (ADRs) for the project.

## ADR Process

1. Identify a decision that needs to be made
2. Create a new ADR using the template
3. Document context, options, and recommendation
4. Submit for ChatGPT review
5. Record decision and rationale

## ADR Naming Convention

```text
ADR-NNN-short-description.md
```

Example: `ADR-001-vpn-protocol-selection.md`

## ADR Statuses

- `PROPOSED` — Under discussion
- `ACCEPTED` — Decision made, implementation pending
- `DEPRECATED` — Superseded by another ADR
- `SUPERSEDED` — Replaced by ADR-NNN
