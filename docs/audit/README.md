This directory contains audit-related documents, including the initial concept that serves as the starting point for this project.

## Contents

## Audit Process

Each stage produces audit artifacts:

- Stage report (`stages/stage-NN/report.md`)
- Acceptance record (`stages/stage-NN/acceptance.md`)
- Evidence files (`evidence/stage-NN/`)

External audit is performed by ChatGPT via GitHub connector.
